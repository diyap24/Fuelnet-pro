# FuelNet Pro — Fuel Efficiency Prediction System

> Industrial-grade neural network system for predicting vehicle fuel efficiency (MPG).  
> Stack: Node.js · TensorFlow.js · Express · Chart.js

---

## Step-by-Step Setup Guide

### Prerequisites

Make sure you have these installed:

| Tool        | Version  | Check with         |
|-------------|----------|--------------------|
| Node.js     | ≥ 18.0   | `node --version`   |
| npm         | ≥ 9.0    | `npm --version`    |
| VS Code     | latest   |                    |

---

### Step 1 — Open the project in VS Code

```bash
# If you cloned or copied the folder:
code /path/to/fuelnet

# Or open VS Code, then: File → Open Folder → select the fuelnet folder
```

---

### Step 2 — Install dependencies

Open the VS Code integrated terminal (`Ctrl+`` ` or Terminal → New Terminal) and run:

```bash
npm install
```

This installs TensorFlow.js, Express, Winston, and all other dependencies.

> **Note:** TensorFlow.js native bindings (`@tensorflow/tfjs-node`) compile a C++ addon.  
> This may take 2–5 minutes on first install. If you see Python/build warnings, they are normal.

---

### Step 3 — Configure environment

```bash
cp .env.example .env
```

The defaults work out of the box. Edit `.env` only if you need custom paths or ports.

---

### Step 4 — Generate the training dataset

```bash
npm run seed
```

This creates `data/vehicles.csv` with **8,428 synthetic vehicle records**.  
You'll see output like:

```
[2024-01-01 12:00:00] info: Seeding dataset: 8428 records → data/vehicles.csv
[2024-01-01 12:00:01] info: Dataset seeding complete.
```

---

### Step 5 — Train the neural network

```bash
npm run train
```

This will:
1. Load and normalize the dataset
2. Build the NN: **7 → 64 → 128 → 64 → 1** with ReLU, BatchNorm, and Dropout
3. Train for 100 epochs with Adam optimizer
4. Save the best checkpoint to `models/fuelnet_model/`
5. Write `models/training_history.json`

Expected output:
```
[info] Model built { layers: 12, params: 26177 }
[info] Starting training...
[info] [epoch  10] loss=1.4821 val_loss=1.6203
[info] [epoch  20] loss=0.7012 val_loss=0.8111 ✓ best
...
[info] [epoch 100] loss=0.0214 val_loss=0.0318 ✓ best
[info] Training complete in 42.3s — best val_loss=0.0318 at epoch 100
[info] Test results: MSE=0.0318 MAE=0.1312 R²=0.9360
```

Training takes roughly **30–90 seconds** on a modern laptop.

---

### Step 6 — Evaluate the model (optional)

```bash
npm run evaluate
```

Prints full metrics on the held-out test set:

```
Samples : 1686
RMSE    : 1.84 MPG
MAE     : 1.31 MPG
MAPE    : 5.21 %
R²      : 0.9360
P50 abs error: 1.12 MPG
P90 abs error: 3.71 MPG
P95 abs error: 4.92 MPG
```

---

### Step 7 — Start the server

```bash
npm start
```

Or for development with auto-reload:

```bash
npm run dev
```

The server starts at **http://localhost:3000**

---

### Step 8 — Open the dashboard

Navigate to **http://localhost:3000** in your browser.

The dashboard has four tabs:
- **Predict** — adjust sliders and get real-time MPG predictions
- **Train** — configure hyperparameters and simulate training
- **Analytics** — loss curves, scatter plots, SHAP importance charts
- **Dataset** — preview the training data with error analysis

## API Reference

All endpoints are prefixed with `/api`.

### `GET /api/health`
Returns server and model status.

```json
{ "status": "ok", "model": "loaded", "uptime_s": 120 }
```

### `GET /api/model/info`
Returns model architecture, input feature definitions, and metrics.

### `POST /api/predict`
Single-vehicle prediction.

**Request body:**
```json
{
  "displacement": 2.5,
  "horsepower": 150,
  "weight": 3200,
  "cylinders": 4,
  "modelYear": 2018,
  "drivetrain": 1,
  "transmission": 0
}
```

**Drivetrain:** 0=FWD, 1=RWD, 2=AWD, 3=4WD  
**Transmission:** 0=Auto, 1=Manual, 2=CVT

**Response:**
```json
{
  "success": true,
  "data": {
    "predicted_mpg": 28.4,
    "city_mpg": 24.1,
    "highway_mpg": 33.2,
    "co2_g_per_mile": 313,
    "efficiency_class": "B",
    "annual_fuel_cost_usd": 1875,
    "feature_importance": { "weight": 0.31, "horsepower": 0.27, "..." : "..." },
    "model_info": { "architecture": "7→64→128→64→1", "r2_score": 0.936 },
    "latency_ms": 3
  }
}
```

### `POST /api/predict/batch`
Predict for up to 100 vehicles at once.

**Request body:**
```json
{ "vehicles": [ { ...vehicle1 }, { ...vehicle2 } ] }
```

### `GET /api/history`
Returns the training history JSON (loss curves, final metrics).

## Common Issues

**`Error: No trained model found`**  
→ Run `npm run train` first.

**`Dataset not found`**  
→ Run `npm run seed` first.

**TensorFlow native addon fails to build**  
→ Ensure you have Python 3.x and build tools: `npm install -g node-gyp`  
→ On Windows: `npm install --global --production windows-build-tools`

**Port 3000 already in use**  
→ Change `PORT=3001` in your `.env` file.

## Model Architecture

```
Input (7 features)
    ↓
Dense(64, ReLU) → BatchNorm → Dropout(0.2)
    ↓
Dense(128, ReLU) → BatchNorm → Dropout(0.2)
    ↓
Dense(64, ReLU) → BatchNorm → Dropout(0.2)
    ↓
Dense(1, Linear)   ← predicted MPG (normalized)
```

- **Loss:** Mean Squared Error
- **Optimizer:** Adam (lr=0.001)
- **Regularization:** L2 kernel + Dropout + BatchNorm
- **Parameters:** ~26,000
